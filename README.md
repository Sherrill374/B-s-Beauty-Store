
# Beauty Supply Store Web Application

## Project Summary
This project is a PHP web application connected to a MySQL database. The application was developed throughout the course using PHP, MySQL, XAMPP, and GitHub. The project includes a database connection, product display functionality, basic shopping cart structure, and multiple PHP pages organized into folders for maintainability.

The purpose of the application is to simulate an online beauty supply store where users can view products and interact with the website using PHP server-side scripting and database integration.

Technologies used:
- PHP
- MySQL
- XAMPP
- GitHub
- Visual Studio Code
